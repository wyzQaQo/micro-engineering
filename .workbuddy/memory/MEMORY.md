# Micro Engineering Machinery - Project Memory

## Project
B2B外贸独立站 for mini excavator attachments / skid steer attachments.
Positioned as "工业属具 SEO RFQ引擎" - not e-commerce.

## Design Direction
- Dark industrial theme (#0a0f1a base, amber accent)
- Geist font family
- Tailwind v4 + shadcn/ui
- Next.js 16 App Router
- next-intl for i18n (9 languages)

## Key Conventions
- All CTAs use "Get a Quote" intent (no duplicates)
- WhatsApp floating button only (no live chat widgets)
- Product cards use SpotlightCard hover effect
- Specs displayed as card grid (not boring tables)
- RFQ form is core conversion point
- SSG for all category and product pages
